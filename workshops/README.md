# SCM Workshops for Enterprise DevOps

This workshop track introduces source control management (SCM) fundamentals and applies them to common enterprise DevOps scenarios.

## Learning Path

### Foundations
1. [Workshop 01 - SCM Fundamentals](./foundations/01-scm-fundamentals.md)
2. [Workshop 02 - Branching and Collaboration](./foundations/02-branching-and-collaboration.md)
3. [Workshop 03 - Release and Traceability](./foundations/03-release-and-traceability.md)

### Enterprise Scenarios
4. [Workshop 04 - Trunk-Based Development in Enterprises](./scenarios/04-trunk-based-development-enterprise.md)
5. [Workshop 05 - Regulated Change Control](./scenarios/05-regulated-change-control.md)
6. [Workshop 06 - Incident Response and Hotfix Flow](./scenarios/06-incident-response-hotfix-flow.md)

## Recommended Delivery Format
- Audience: developers, DevOps engineers, release managers, and team leads
- Session length: 60 to 90 minutes per workshop
- Style: short concepts + guided exercises + team discussion

## Outcomes
By completing this track, participants will be able to:
- explain SCM principles in enterprise software delivery
- apply branch and review strategies based on team and compliance needs
- design release flows with strong traceability
- respond to production incidents using controlled hotfix patterns
