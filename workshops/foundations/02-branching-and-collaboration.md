# Workshop 02 - Branching and Collaboration

## Goal
Choose and apply a branching model that supports team velocity and quality.

## Topics
- Feature branches, trunk-based development, and release branches
- Pull request flow and peer review expectations
- Merge strategies: merge commit, squash, and rebase
- Conflict management and synchronization practices

## Hands-On Activities
1. Create a feature branch from the main branch.
2. Simulate parallel changes and resolve a merge conflict.
3. Open a pull request and perform structured review feedback.
4. Merge using different strategies and compare resulting history.

## Enterprise Discussion Prompts
- Which branching model fits your deployment frequency?
- When should squash merges be required?
- What branch protection rules are critical for your organization?

## Deliverables
- A documented branching policy for the team
- A pull request checklist including testing and review gates
