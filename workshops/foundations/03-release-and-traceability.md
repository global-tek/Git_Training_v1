# Workshop 03 - Release and Traceability

## Goal
Connect SCM practice to release governance and production accountability.

## Topics
- Semantic versioning and release tags
- Mapping commits to work items and change requests
- Release notes generation from commit and PR history
- Rollback and forward-fix strategies

## Hands-On Activities
1. Tag a release candidate and a production release.
2. Generate release notes from merged pull requests.
3. Trace a production issue back to its originating commit and PR.
4. Execute a rollback rehearsal and capture recovery evidence.

## Enterprise Discussion Prompts
- How do you prove what code is running in production?
- What metadata is mandatory for compliance reporting?
- How should rollback authority be defined during high-risk releases?

## Deliverables
- A release tagging convention
- A traceability matrix linking work item -> PR -> commit -> release
