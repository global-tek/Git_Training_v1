# Workshop 01 - SCM Fundamentals

## Goal
Build a shared understanding of SCM concepts and why they matter in enterprise DevOps.

## Topics
- What SCM solves: history, collaboration, traceability, and rollback
- Repository anatomy: working tree, staging area, commits, refs
- Commit quality: atomic changes, meaningful messages, and reviewability
- Core operations: add, commit, branch, merge, revert, cherry-pick

## Hands-On Activities
1. Initialize a repository and create an initial commit.
2. Create multiple small commits to model incremental change.
3. Use history inspection to identify when and why a change was introduced.
4. Revert a problematic commit while preserving audit history.

## Enterprise Discussion Prompts
- What does “good commit hygiene” look like in your teams?
- Which audit expectations require clean and descriptive commit trails?
- How should teams balance commit frequency vs. review overhead?

## Deliverables
- A sample commit history that demonstrates clean, atomic changes
- Team agreement on commit message structure and minimum standards
